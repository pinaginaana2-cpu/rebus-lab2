Лабораторная работа № 2. Числовые ребусы
Программа на C решает числовые ребусы, например SEND + MORE = MONEY -> 9567 + 1085 = 10652.
Правила: буквы в верхнем регистре; одна буква - одна цифра; ведущие нули запрещены;в одном ребусе один оператор: + (сложение, 2 и более слагаемых), - (вычитание),* (умножение, 2 и более сомножителей), / (деление). Ребус должен содержать знак = и результат справа от него.
Порядок работы: базовое решение, затем оптимизации (каждая отдельным коммитом),затем сравнение скорости до и после оптимизаций.
Сборка: clang -std=gnu11 -O2 -o rebus rebus.c
